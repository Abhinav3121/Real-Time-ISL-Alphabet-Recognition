================================================================
  Real-Time ISL Alphabet Recognition System
================================================================

A real-time Indian Sign Language recognition system using
MediaPipe for hand landmark detection and a TensorFlow/Keras
neural network for classification. The app streams live webcam
video through a Flask web interface and predicts ISL signs.


----------------------------------------------------------------
  PROJECT STRUCTURE
----------------------------------------------------------------

  isl-recognition/
  ├── ISL_Data/               # Training images (one subfolder per sign)
  │   ├── A/
  │   ├── B/
  │   └── ...
  ├── static/                 # Flask static assets (CSS, JS, images)
  ├── templates/
  │   └── index.html          # Frontend template for the web app
  ├── collect_data.py         # Step 1: Capture training images via webcam
  ├── process_data.py         # Step 2: Extract hand landmarks from images
  ├── model_training.txt      # Step 3: Model training script (run in Colab)
  ├── app.py                  # Step 4: Flask app for real-time prediction
  ├── landmarks.csv           # Generated landmark feature file
  └── isl_model.h5            # Trained Keras model


----------------------------------------------------------------
  REQUIREMENTS
----------------------------------------------------------------

  Python 3.8+

  Install dependencies:

      pip install opencv-python mediapipe tensorflow flask numpy pandas scikit-learn tqdm


----------------------------------------------------------------
  HOW TO RUN (Step-by-Step)
----------------------------------------------------------------

  STEP 1 — Collect Training Data
  --------------------------------
  Run collect_data.py to capture images for each ISL sign.

      python collect_data.py

  - Enter the sign name when prompted (e.g., "A", "Hello", etc.).
  - The webcam starts automatically after a 5-second countdown.
  - 400 images are captured per sign at 0.1-second intervals.
  - Images are saved to ISL_Data/<sign_name>/.
  - Press 'Q' to quit early.
  - Repeat for every sign you want to recognize.


  STEP 2 — Process Data & Extract Landmarks
  -------------------------------------------
  Run process_data.py to extract hand landmarks from all images.

      python process_data.py

  - Reads all images from the ISL_Data/ folder.
  - Uses MediaPipe to detect up to 2 hands per image.
  - Extracts (x, y) coordinates for 21 landmarks per hand = 42 values per hand.
  - For single-hand signs, pads with zeros to maintain a fixed 84-feature vector.
  - Saves all features and labels to landmarks.csv.


  STEP 3 — Train the Model
  -------------------------
  Open model_training.txt and run it as a Python script, or
  paste it into a Google Colab notebook (recommended for GPU).

  - Upload landmarks.csv to Colab.
  - The script builds a 3-layer Dense neural network:
        Input(84) → Dense(128, ReLU) → Dropout(0.3)
                  → Dense(64, ReLU)  → Dropout(0.3)
                  → Dense(num_classes, Softmax)
  - Trains for 800 epochs with Adam optimizer.
  - Prints test accuracy and loss after training.
  - Saves the trained model as isl_model.h5.
  - Download isl_model.h5 and place it in the project root.


  STEP 4 — Run the Web App
  -------------------------
  Start the Flask app for real-time recognition:

      python app.py

  - Open your browser and go to: http://127.0.0.1:5000
  - The webcam feed is displayed live on the page.
  - Detected hand landmarks are drawn on the video.
  - The predicted ISL sign is shown in green text on the frame.


----------------------------------------------------------------
  HOW IT WORKS
----------------------------------------------------------------

  1. MediaPipe detects hand landmarks in each video frame.
  2. (x, y) coordinates of 21 keypoints per hand are extracted.
  3. The 84-feature vector is fed into the trained neural network.
  4. The model outputs a probability for each sign class.
  5. The class with the highest probability is displayed.


----------------------------------------------------------------
  NOTES
----------------------------------------------------------------

  - Ensure good lighting and a plain background for best accuracy.
  - Collect data for all signs before running process_data.py.
  - The model supports both one-hand and two-hand ISL signs.
  - For one-hand signs, the second hand's features are zero-padded
    so the input shape stays consistent at 84 features.
  - Training in Google Colab with a GPU is strongly recommended
    due to the 800-epoch training configuration.
  - The LABELS list in app.py is auto-generated by reading the
    ISL_Data/ subfolder names in sorted order — make sure this
    matches the order used during training.


----------------------------------------------------------------
  TROUBLESHOOTING
----------------------------------------------------------------

  Webcam not opening:
    → Make sure no other application is using the webcam.
    → Try changing cv2.VideoCapture(0) to cv2.VideoCapture(1).

  Low prediction accuracy:
    → Collect more images per sign (increase num_images_per_sign).
    → Ensure consistent hand positioning during data collection.
    → Try increasing the number of training epochs.

  MediaPipe not detecting hands:
    → Improve lighting conditions.
    → Lower min_detection_confidence to 0.3 in the Hands() config.

  Model file not found:
    → Make sure isl_model.h5 is in the same directory as app.py.
